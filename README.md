# sadakat-ve-puan-yonetimi
Proje işletmelerin müşteri sadakatini arttırmak için kullandıkları bir sistemdir bu sistemde üyeler alışveriş yaptıkça çeşitli seviyelere ulaşırlar ve bunun sonucunda da  seviyeleriyle doğru orantılı olacak şekilde hediyeler sunulmaktadır  bu sayede müşterilerin markalara bağımlılığının artması hedeflenmektedir.
